# 🧮 Calculator

A clean, minimal web-based calculator built with HTML, CSS, and JavaScript.

---

## 📸 Preview

A simple 4-function calculator with a responsive layout, styled header and footer, and a smooth button interaction experience.

---

## 🚀 Features

- Basic arithmetic operations — addition, subtraction, multiplication, and division
- Clear button to reset the display
- Clean, minimal UI with a fixed header and footer
- Responsive button grid layout
- Visual distinction between number and operation buttons

---

## 📁 Project Structure

```
calculator/
├── index.html      # Main HTML structure
├── style.css       # Styling and layout
└── script.js       # Calculator logic
```

---

## 🛠️ How to Run

No installation or build tools required.

1. Clone or download the repository
2. Open `index.html` in any modern web browser

```bash
git clone https://github.com/your-username/calculator.git
cd calculator
open index.html
```

---

## 🧩 Usage

| Button | Action |
|--------|--------|
| `0–9` | Input a digit |
| `+` `-` `*` `/` | Choose an operation |
| `=` | Evaluate the expression |
| `clear` | Reset the display |

---

## 🎨 Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Page structure |
| CSS3 | Styling and layout |
| JavaScript | Calculator logic |

---

## 📌 Notes

- The calculator evaluates expressions sequentially as typed
- Dividing by zero will show an `Error` — clear and try again
- Works entirely in the browser with no external dependencies
